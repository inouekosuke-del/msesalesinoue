# 朝礼ボード データ層の診断・修復ツール

[`docs/chorei-board-audit-2026-09-11.md`](../../docs/chorei-board-audit-2026-09-11.md) で
検出した不具合のうち、**データ側だけで直せるものを直す**ための追加スクリプト。

朝礼ボードのアプリ本体（コンテナバインドのGAS）には一切触らない。
関数名も日本語にしてあるので、既存の関数と名前が衝突する心配はない。

| ファイル | 役割 |
|---|---|
| `ChoreiFix.gs` | 診断と修復。シートはヘッダー行の組み合わせで特定する |
| `ChoreiAgg.gs` | 「正しい集計」の参照実装。画面の数字と突き合わせる対照表を作る |
| `test/` | GASをスタブしてNodeで流す回帰テスト |

## 手順

### 1. 追加する

朝礼ボードのスプレッドシートを開き、**拡張機能 > Apps Script**。
`ChoreiFix.gs` と `ChoreiAgg.gs` の中身を、それぞれ新規ファイルとして貼る。

### 2. 診断する（読み取りのみ）

`診断()` を実行。`_診断レポート` シートに現状が出る。

2026-09-11 のデータでの結果:

| 区分 | 項目 | 件数 |
|---|---|---:|
| 取り込み | TODOにあって案件テーブルに無い案件 | 243件 / ￥257,055,092 |
| 取り込み | 確度 A / C / C+ の案件 | **0件**（計上予定レポートを読んでいるため） |
| 名寄せ | 案件の `ownerId` が空 | 2行 / ￥8,780,000 |
| 名寄せ | 日次履歴の `memberId` が空 | 78行 |
| 月キー | ゼロ埋めされていない月キー | 22セル |
| キー | `lineId` の衝突 | 4件 |
| キー | `oppId` が空 | 129 / 129行 |
| 目標 | members と monthTargets の食い違い | 3件 |
| 目標 | monthTargets に行が無い在籍メンバー | 8名 |
| TODO | `todoTitle` が埋まっている行 | 0 / 310行 |

### 3. 名寄せできない担当を登録する

`メンバー追加候補()` を実行。実行ログに `members` シートへ貼れる行が出る。
2026-09-11 時点では吉牟田さん・小菅さんの2名。
**この2名を追加してから修復に進むこと。** 追加しないと名寄せがスキップされる。

退職・異動済みなら `active` を `FALSE` にする。過去分の名寄せは `active` に関係なく効く。

### 4. 修復する

```
修復_ドライラン()   ← 何をどう変えるかだけ出す。書き込みなし
修復_実行()         ← バックアップを作ってから適用する
```

`修復_実行()` は最初に `DriveApp.makeCopy()` でスプレッドシート全体のコピーを作る。
コピーのURLは実行ログに出る。行の削除はしない。値の上書きだけ。

何度実行しても結果は同じ（冪等）。2回目の `修復_ドライラン()` は 0 セルになる。

### 5. 数字を突き合わせる

`検算_今月()` を実行。`_集計検算` シートに、担当者別の受注／計上見込みが出る。
**これと画面の数字が合わなければ、画面側の集計が間違っている。**

`ChoreiAgg.gs` の集計は4つの約束を守っている:

1. **`side` を必ず指定する** — 案件は受注行と計上行の2行ある。省くと必ず倍になる
2. **月キーは `toMonthKey_()` で作る** — `'2026-9'` と `'2026-09'` を取り違えない
3. **担当は名寄せしてから集計する** — `ownerId` が空でも `ownerName` から引き直す
4. **知らない進捗は捨てずに返す** — SFに進捗が増えても静かに消えず `unknownStages` に出る

## このツールで直らないもの

| 不具合 | なぜ直らないか | どこを直すか |
|---|---|---|
| 見込み案件がほぼ入っていない（確度A/C/C+が0件） | 読んでいるレポートの種類が違う | Salesforceレポートの差し替え |
| `oppId` が全行空 | 取得列に無い | Salesforceレポートの列 |
| TODOの件名・状況が空 | 同上 | 同上 |
| 完了した指示が再表示される | アプリ本体のコード | 朝礼ボードのGAS本体 |
| クリックで先頭にスクロールする | アプリ本体のHTML/JS | 同上 |

下2つを直すには本体のソースが要る。取り込み手順は
[`docs/chorei-board-audit-2026-09-11.md`](../../docs/chorei-board-audit-2026-09-11.md) の末尾。

## 取り込み側を直すとき

`toMonthKey_()` / `safeDate_()` / `normName_()` / `memberIndex_()` は
`ChoreiFix.gs` に単独で完結する形で置いてある。
本体の取り込み処理からそのまま呼べるので、月キーの生成と名寄せはこれに寄せること。
そうすれば、以後は修復が要らなくなる。
