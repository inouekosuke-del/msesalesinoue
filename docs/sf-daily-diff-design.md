# Salesforce日次差分・活動量可視化 設計メモ

調査日: 2026-09-14

## 要件

1. **毎日差分** — Salesforceの案件が前日から何が動いたか（新規／受注／失注／確度変動／金額変更／日付スライド）を毎日見たい
2. **活動量** — メンバーがどのくらい動けているか。特に **2週間動いていない案件** を出したい

## 結論：取り込みパイプラインは既に動いている

「GmailでCSVを飛ばす」は新規に作る必要がない。**すでに毎日動いている。**

```
Salesforce レポート購読
  → Gmail（井上さん宛）「レポート結果 (…)」メール
  → 何らかのGASが毎朝パース・Gmailに「MSE朝礼/取込済」ラベル付与
  → MSE朝礼ボード_データ／取込_案件 タブへ書き込み
```

## ギャップ1：履歴が残っていない

サンプルした行の `importedAt` が全て同一値であることから、
`取込_案件` は**毎朝の全置換**と見られる（未確定。GASソース確認が必要）。
昨日の状態が残らないため、そのままでは差分が取れない。

**ただし過去のレポートメールはGmailに残っている。**
新たなストレージを足さなくても、任意の2時点のメールを再パースすれば差分は算出できる。

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| A | `取込_案件` を追記式にする／`履歴` タブを足す | 日次アラートとして高速に回せる | GAS改修が必要（ソース未取得のため着手不可） |
| B | Gmailの過去メールを都度パースして2時点比較 | 実装不要・**今日からできる**・過去に遡れる | 毎回パースするので遅い |

**推奨**：まずBで差分の中身を確定させ、定常運用に乗せる段でAを足す。

## ギャップ2：lineId の設計が差分に向いていない（最重要）

```
lineId = 株式会社ディクラッセ|BtoBオプション（一式）|300000
                                                    ^^^^^^ 金額がキーに入っている
```

金額を 300,000 → 350,000 に変更すると **lineId が変わる**。
差分処理は「1件消えて1件増えた」と誤判定し、**金額変動を追跡できない**。
毎日いちばん見たい動きが、いちばん取れない構造になっている。

`oppId` 列には商談名（`BtoBオプション／株式会社ディクラッセ`）が入っており、
Salesforceの18桁IDではない。同名商談があれば衝突する。

**対策**：レポートに商談ID・商談商品IDの列を追加し、キーをIDに変更する。

## ギャップ3：「活動量」の定義

| フィールド | 意味 | 用途 |
|---|---|---|
| `sfUpdated`（最終更新日） | 誰かがレコードを触った日。金額を1円直しても更新される | 「放置されている案件」の検出には使える |
| 最終活動日（LastActivityDate） | ToDo・行動が**完了**した日 | 「実際に顧客接触できているか」はこちら |

「2週間動いていない案件」は `sfUpdated` だけでも**今日から出せる**が、
「どのくらい活動できているか」を測るなら最終活動日が要る。現レポートに列がない。

なお次回TODOの期日は `alert-overdue-mse` がToDoリストビュー（`filterName=MSE`）で
既に押さえている。活動量の指標としてはこれと突き合わせる。
