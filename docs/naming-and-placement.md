# データ配置ルールと命名規則

AIオフィスでは「人が探せる」だけでは不十分で、**スキルが機械的に辿れる**必要がある。
そのための最小限のルール。

## 原則

1. **マイドライブ直下にファイルを置かない。** 直下は「まだ分類していない物置」であり、
   ここに置いた瞬間そのファイルは行方不明になる（現状250件超がこの状態）。
2. **スキルはファイル名でデータを探さない。** 参照は必ず `registry/data-sources.yaml` の
   `key` → `id` を経由する。名前で探すスキルは、リネーム時にエラーも出さず壊れる。
3. **台帳に無いデータはAIワークフローの入力にしない。** 逆に、入力にするなら台帳に登録する。

## フォルダ体系

```
マイドライブ/
├── 00_受信箱/          未分類の一時置き場。週次で空にする
├── 10_業績/            KGI・チェックシート・業績レポート
├── 20_案件/
│   └── {会社名}_{YYYYMMDD}/   案件単位。帳票アプリの出力先もここ
├── 30_アプリ/          自作アプリのデータ層とGAS
│   ├── 帳票アプリ/
│   ├── 朝礼ボード/
│   └── 営業行動計画/
├── 40_テンプレート/    見積書雛形など。【テンプレ】接頭辞のもの
├── 50_資料/            提案資料・レビュー資料・議事録
└── 90_アーカイブ/      廃止したが消せないもの。参照禁止
```

## 命名規則

| 種別 | 形式 | 例 |
|---|---|---|
| 業績・管理系 | `mse_{用途}_{年}` | `mse_業績管理_2026` |
| 案件フォルダ | `{会社名}_{YYYYMMDD}` | `富士フイルム株式会社_20260906` |
| 帳票 | `【{帳票種別}】{会社名}_{YYYYMMDD}` | `【見積書】富士フイルム株式会社_20260906` |
| テンプレート | `【テンプレ】{名称}_ver{X.Y}` | `【テンプレ】MSE見積書_ver4.0` |
| 会議メモ | `[会議][{定例/単発}]{名称} - {YYYY/MM/DD HH:MM}` | 既存のGeminiメモ形式を踏襲 |
| アーカイブ | 元の名前の先頭に `_archived_` | `_archived_商談結果` |

**禁止事項**
- 「無題のスプレッドシート」「無題のプロジェクト」のまま放置しない（現状18件以上）
- 日時の秒までを機械的に付けない（`_20260821041309` のような名前は人が読めない）
- 「_更新版」「のコピー」で版を表さない。版は `ver{X.Y}` か日付で表す
- フォルダ名にURLやDrive IDを入れない（現状2件該当）

## 新しくスプレッドシート／アプリを作るときの手順

1. 作る前に `registry/data-sources.yaml` を見て、同じものが既に無いか確認する
2. 上のフォルダ体系のどこに属するか決め、**そのフォルダの中で作る**
3. 命名規則に沿って名前を付ける（作成直後。「あとで」は来ない）
4. スキルやGASから読ませるなら、台帳に `key` / `id` / `role` / `owner` を追記する
5. 参照する側は名前ではなく台帳の `id` を書く

## 棚卸しサイクル

- **週次**：`00_受信箱` を空にする
- **月次**：台帳の `last_modified` を更新し、90日以上更新のないものを `stale` に落とす
- **四半期**：`unknown` のものを調査し、`active` にするか `retired` にするか決める
